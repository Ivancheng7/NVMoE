用户明确说过"基线、冒烟、哈希这种我根本看不懂"。他关心的是产品能不能跑出结果，而不是测试术语。

**Why:** 他是项目决策者但不做底层数值和测试工作，术语会直接阻断沟通，让一次本该有用的进展汇报变得没法用。

**How to apply:** 用日常类比解释概念（哈希 = 内容指纹、冒烟 = 通电看看会不会冒烟、基线 = 标准答案），术语第一次出现时用一句话解释；先说结论再补证据；避免箭头流程图和自造缩写；给证据时说明这份文件能证明什么，而不是只丢路径。
